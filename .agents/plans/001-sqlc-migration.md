# Plan: Migrate Inline SQL to sqlc with Service-Layer Mapping

## Model Flow (Option A)

```
Controller (domain types)
    → Service (domain types)
        → Service maps domain → sqlc types
        → Store (sqlc types)
            → sqlc generated functions OR raw DB queries (hybrid)
        → Store returns sqlc types
        → Service maps sqlc → domain types
    → Service returns domain types
Controller (domain types) → JSON
```

### Phase 1: Static sqlc Queries (single SQL, no dynamic parts)

All of these can be expressed as a single annotated SQL query. sqlc generates the function and result type.

| plant | UpdatePlant | UPDATE plants |
| plant | DeletePlant | DELETE FROM plants |

| plant | DeletePlantImage | DELETE FROM plant_images |

| user | GetAuthTokenByHash | SELECT FROM auth_tokens WHERE token_hash = ? |
| user | MarkAuthTokenUsed | UPDATE auth_tokens SET used_at |

### Phase 2: Dynamic Queries (hybrid — sqlc + raw Go)

These have dynamic parts (IN clauses, scope switching, transactions) that can't be a single static sqlc query.

#### 2A: Sqlc for the main query, Go for batch loading

| Store Method | Sqlc part | Go part |
|---|---|---|
| ListPlantSpecies | scoped filter query with `@scope` param | batch load species images with IN |
| ListPlantsWithSpecies | JOIN query with optional `@species_id` | batch load plant images with IN |
| GetPlantWithSpecies | JOIN query by ID (fully static) | calls GetPlantImages (sqlc, one call) |
| GetPlantSpecies | static query with `@user_id > 0` pattern | batch load species images with IN |
| GetEvents | query by plant_id (fully static) | batch load event images with IN |

#### 2B: Fully Go (cannot be expressed as single sqlc query)

| Store Method | Reason |
|---|---|
| ToggleFavorite | Conditional: check existence → insert OR delete |
| syncSpeciesImages | Transaction: DELETE old + INSERT new images |
| loadEventImages | IN clause |
| GetEventsByDateRange | IN clause from API input + optional eventType |
| GetLastEventDates | IN clause from API + optional eventType |

#### `queries/plant_species.sql`

```sql
-- name: CreatePlantSpecies :execresult
INSERT INTO plant_species
    (common_name, scientific_name, water_profile, light_level, soil_type,
     pet_toxicity, pet_toxicity_notes, categories_json, notes, user_id, visibility, is_quick)
VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?);

-- name: GetPlantSpecies :many
-- Uses @scope to handle visibility filtering.
-- Pass @scope = '' for default (public + user's own), 'mine', 'favorites', etc.
SELECT ps.id, ps.common_name, ps.scientific_name, ps.water_profile,
    ps.light_level, ps.soil_type, ps.pet_toxicity, ps.pet_toxicity_notes,
    coalesce(ps.categories_json, '[]') as categories_json,
    ps.notes, ps.user_id, ps.visibility,
    coalesce(u.username, '') as author_username,
    ps.created_at, ps.updated_at, ps.is_quick, ps.deleted_at,
    coalesce((SELECT count(*) FROM plants WHERE plant_species_id = ps.id AND user_id = ?), 0) as user_plant_count,
    CASE WHEN EXISTS (SELECT 1 FROM plant_species_favorites WHERE plant_species_id = ps.id AND user_id = ?)
         THEN 1 ELSE 0 END as is_favorited
FROM plant_species ps
LEFT JOIN users u ON u.id = ps.user_id
WHERE
  (
    (@scope = '' AND (ps.visibility = 'public' OR (@user_id > 0 AND ps.user_id = @user_id)))
    OR (@scope = 'mine' AND ps.user_id = @user_id)
    OR (@scope = 'favorites' AND EXISTS (SELECT 1 FROM plant_species_favorites WHERE plant_species_id = ps.id AND user_id = @user_id))
    OR (@scope = 'linked' AND EXISTS (SELECT 1 FROM plants WHERE plant_species_id = ps.id AND user_id = @user_id))
    OR (@scope = 'mine-favorites' AND (
        ps.user_id = @user_id
        OR EXISTS (SELECT 1 FROM plant_species_favorites WHERE plant_species_id = ps.id AND user_id = @user_id)
        OR EXISTS (SELECT 1 FROM plants WHERE plant_species_id = ps.id AND user_id = @user_id)
    ))
  )
  AND ps.deleted_at IS NULL
ORDER BY ps.common_name ASC;

-- name: GetPlantSpeciesByID :one
SELECT ps.id, ps.common_name, ps.scientific_name, ps.water_profile,
    ps.light_level, ps.soil_type, ps.pet_toxicity, ps.pet_toxicity_notes,
    coalesce(ps.categories_json, '[]') as categories_json,
    ps.notes, ps.user_id, ps.visibility,
    coalesce(u.username, '') as author_username,
    ps.created_at, ps.updated_at, ps.is_quick, ps.deleted_at,
    coalesce((SELECT count(*) FROM plants WHERE plant_species_id = ps.id AND user_id = @user_id), 0) as user_plant_count,
    CASE WHEN EXISTS (SELECT 1 FROM plant_species_favorites WHERE plant_species_id = ps.id AND user_id = @user_id)
         THEN 1 ELSE 0 END as is_favorited
FROM plant_species ps
LEFT JOIN users u ON u.id = ps.user_id
WHERE ps.id = @id
  AND (ps.visibility = 'public' OR (@user_id > 0 AND ps.user_id = @user_id));

-- name: UpdatePlantSpecies :exec
UPDATE plant_species
SET common_name = ?, scientific_name = ?, water_profile = ?, light_level = ?,
    soil_type = ?, pet_toxicity = ?, pet_toxicity_notes = ?,
    categories_json = ?, notes = ?, visibility = ?, is_quick = ?,
    updated_at = datetime('now', 'localtime')
WHERE id = ? AND user_id = ?;

-- name: SoftDeletePlantSpecies :exec
UPDATE plant_species SET deleted_at = datetime('now', 'localtime')
WHERE id = ? AND user_id = ?;

-- name: ExistsPlantSpecies :one
SELECT 1 FROM plant_species WHERE id = ? AND deleted_at IS NULL;

-- name: CountImageReferences :one
SELECT count(*) FROM plant_species_images WHERE filepath = ?;

-- name: GetSpeciesImageFilepaths :many
SELECT filepath FROM plant_species_images WHERE plant_species_id = ?;

-- name: GetSpeciesImages :many
SELECT id, plant_species_id, filepath, position
FROM plant_species_images
WHERE plant_species_id = ?
ORDER BY position ASC;
```

#### `queries/plants.sql`

```sql
-- name: CreatePlant :execresult
INSERT INTO plants (nickname, source, plant_species_id, acquired_at, notes, user_id)
VALUES (?, ?, ?, ?, ?, ?);

-- name: GetPlantByID :one
SELECT id, nickname, source, plant_species_id, acquired_at, notes, user_id, created_at, updated_at
FROM plants
WHERE id = ? AND user_id = ?;

-- name: UpdatePlant :exec
UPDATE plants
SET nickname = ?, source = ?, acquired_at = ?, notes = ?,
    updated_at = datetime('now', 'localtime')
WHERE id = ? AND user_id = ?;

-- name: DeletePlant :exec
DELETE FROM plants WHERE id = ? AND user_id = ?;

-- name: ListPlantsWithSpecies :many
SELECT p.id, p.nickname, p.source, p.acquired_at, p.notes,
    p.created_at, p.updated_at,
    sp.id as species_id, sp.common_name, sp.scientific_name,
    sp.user_id as species_user_id, sp.visibility as species_visibility,
    sp.deleted_at as species_deleted_at,
    coalesce(
        (SELECT json_extract(metadata, '$.location') FROM plant_events
         WHERE plant_id = p.id AND event_type = 'location_change'
         ORDER BY event_date DESC, id DESC LIMIT 1),
        ''
    ) as location
FROM plants p
INNER JOIN plant_species sp ON sp.id = p.plant_species_id
WHERE p.user_id = @user_id
  AND (@species_id = 0 OR p.plant_species_id = @species_id)
ORDER BY p.nickname ASC;

-- name: GetPlantWithSpecies :one
SELECT p.id, p.nickname, p.source, p.acquired_at, p.notes,
    p.created_at, p.updated_at,
    sp.id as species_id, sp.common_name, sp.scientific_name,
    sp.user_id as species_user_id, sp.visibility as species_visibility,
    sp.deleted_at as species_deleted_at,
    coalesce(
        (SELECT json_extract(metadata, '$.location') FROM plant_events
         WHERE plant_id = p.id AND event_type = 'location_change'
         ORDER BY event_date DESC, id DESC LIMIT 1),
        ''
    ) as location
FROM plants p
INNER JOIN plant_species sp ON sp.id = p.plant_species_id
WHERE p.id = @id AND p.user_id = @user_id;
```

```sql
-- name: CreateEvent :execresult
INSERT INTO plant_events (plant_id, event_type, event_date, notes, metadata, user_id)
VALUES (?, ?, ?, ?, ?, ?);

-- name: GetEvent :one
SELECT id, plant_id, event_type, event_date, notes, metadata, created_at, user_id
FROM plant_events
WHERE id = ?;

-- name: DeleteEvent :exec
DELETE FROM plant_events WHERE id = ?;

-- name: GetEventsByPlant :many
SELECT id, plant_id, event_type, event_date, notes, metadata, created_at, user_id
FROM plant_events
WHERE plant_id = ?
ORDER BY event_date DESC, id DESC;

-- name: GetCalendarEvents :many
SELECT id, event_type, event_date
FROM plant_events
WHERE plant_id = ? AND event_date >= ? AND event_date <= ?
ORDER BY event_date DESC;

-- name: GetEventsByDateRange :many
SELECT id, plant_id, event_type, event_date, notes, metadata, created_at, user_id
FROM plant_events
WHERE plant_id IN (sqlc.slice('plant_ids'))
  AND event_date >= @start_date AND event_date <= @end_date
  AND (@event_type IS NULL OR event_type = @event_type)
ORDER BY plant_id, event_date DESC;

-- name: GetLastEventDates :many
SELECT p.id as plant_id, MAX(e.event_date) as last_date
FROM plants p
LEFT JOIN plant_events e ON e.plant_id = p.id
    AND (@event_type IS NULL OR e.event_type = @event_type)
WHERE p.id IN (sqlc.slice('plant_ids'))
GROUP BY p.id;
```

### Step 5: Update Store Implementations

#### `domain/plant/store.go`

The store holds:
```go
type Store struct {
    db      *sql.DB
    queries *sqlc.Queries
}

func NewStore(db *sql.DB) *Store {
    return &Store{
        db:      db,
        queries: sqlc.New(db),
    }
}
```

For each static sqlc query method, delegate to `s.queries`:

```go
func (s *Store) ExistsPlantSpecies(id int64) (bool, error) {
    _, err := s.queries.ExistsPlantSpecies(context.Background(), id)
    if err == sql.ErrNoRows {
        return false, nil
    }
    if err != nil {
        return false, fmt.Errorf("exists species: %w", err)
    }
    return true, nil
}

func (s *Store) GetPlant(id int64, userID int64) (*sqlc.Plant, error) {
    p, err := s.queries.GetPlantByID(context.Background(), sqlc.GetPlantByIDParams{
        ID:     id,
        UserID: userID,
    })
    if err == sql.ErrNoRows {
        return nil, nil
    }
    if err != nil {
        return nil, fmt.Errorf("get plant: %w", err)
    }
    return &p, nil
}
```

For hybrid methods, call sqlc then compose with Go batch loading:

```go
func (s *Store) ListPlantSpecies(userID int64, scope string) ([]sqlc.GetPlantSpeciesRow, error) {
    species, err := s.queries.GetPlantSpecies(context.Background(), sqlc.GetPlantSpeciesParams{
        UserID: userID,
        Scope:  scope,
    })
    if err != nil {
        return nil, fmt.Errorf("list species: %w", err)
    }
    if len(species) == 0 {
        return species, nil
    }

    ids := make([]int64, len(species))
    for i, sp := range species {
        ids[i] = sp.ID
    }

    images, err := s.loadSpeciesImages(ids)
    if err != nil {
        return nil, err
    }
    // attach images to species (may need a custom field or separate handling)
    // TODO: determine how images get attached to sqlc types
    _ = images
    return species, nil
}
```

For fully Go methods (ToggleFavorite, syncSpeciesImages, loadEventImages, GetEventsByDateRange, GetLastEventDates), keep raw `s.db.Exec`/`s.db.Query` but scan into sqlc types.

```go
func (s *Service) GetPlant(id int64, userID int64) (*PlantWithSpecies, error) {
    p, err := s.store.GetPlantWithSpecies(id, userID)
    if err != nil {
        return nil, err

        return nil, &ValidationError{Field: "id", Message: "Planta no encontrada"}

    images, err := s.store.GetPlantImages(id)
    if err != nil {
        return nil, err
    }

    return mapToPlantWithSpecies(*p, images), nil
}
```

## Open Questions / Decisions During Implementation

1. **sqlc model for Metadata**: `PlantEvent.Metadata` is `json.RawMessage` in the domain but a `string` in the DB. Will the sqlc model use `string`? The service mapper converts.

2. **Species images on ListSpecies**: sqlc's `GetPlantSpeciesRow` won't have an `Images` field. The service will need to call `GetSpeciesImages` separately or the batch loader attaches them in the store. **Recommendation**: The store method does the batch load and returns enriched sqlc types, or the service calls a separate image-loading method. Decide per method.

3. **`sqlc.slice()` for IN clauses** in `GetEventsByDateRange` / `GetLastEventDates`: Test if this works with your sqlc version for SQLite. If not, keep those queries as fully raw Go (scan into sqlc types manually).

4. **Transaction for syncSpeciesImages**: This stays as Go with `s.db.Begin()`. The store method manually scans individual rows into sqlc types or uses the generated `CreateSpeciesImage` function within the transaction.
